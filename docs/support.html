EarsMixer

Support

EarsMixer lets you control your own in-ear monitor mix from your phone, connected to a DiGiCo sound desk through an EarsMixer server on the same network.

Before you start

  • Someone needs to be running the EarsMixer server (the desktop app) on the same Wi-Fi network as your phone.
  • Your phone must be on that same network — not on mobile data or a guest network.
  • If the server requires a PIN, ask the engineer for it.

Connecting

  1. Open the app and choose your mixer, or scan the QR code shown in the EarsMixer server’s dashboard.
  2. Enter the PIN if you are asked for one. You only do this once per mixer.
  3. Set a nickname so the engineer knows which mix is yours.
  4. Pick your AUX mix and adjust your channels.

Common questions

The app can’t find or reach the mixer

Check that your phone and the server are on the same network, that the server is running, and that the address is correct. A firewall on the server’s computer can also block the connection.

My PIN isn’t accepted

The engineer may have changed it or signed devices out. Ask them for the current PIN and try again.

It keeps asking for the PIN

If the server’s PIN was changed, every device has to enter the new one. Enter it once more and you’ll stay signed in until it changes again.

I was disconnected mid-use

Brief network drops reconnect on their own. If it stays disconnected, re-open the app and check you’re still on the right network.

Can I try it without a desk?

Yes — the app includes a demo mode so you can explore the controls without a server.
